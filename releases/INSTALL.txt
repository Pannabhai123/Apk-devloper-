DREAM CLASSES PPT MAKER — ANDROID INSTALL
Version 1.1.0 | Package: in.dreamclasses.pptmaker | Android 6.0+

1. Install Dream_Classes_PPT_Maker.apk on your phone.
2. The app needs the Dream Classes FastAPI backend. Deploy it with Docker
   or run it on a computer on the same Wi-Fi network.
3. Open the app > Settings > Backend connection.
4. Enter your server URL, then tap Test & save:
   https://your-server.com
   OR http://YOUR-COMPUTER-LAN-IP:8000
   (/api is added automatically.)
5. Upload a PDF. Extraction, PPT generation, and download are automatic.
   Files are saved to phone Downloads.

The Arena development preview URL is not embedded and will not work as a
permanent public backend. Use HTTPS for a public server. HTTP is only for a
trusted local network.
